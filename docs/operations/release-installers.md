# Release Installers (Windows, macOS, Linux)

This project now publishes installer artifacts for desktop platforms through the existing release pipeline.

## Trigger a release

1. Open GitHub Actions and run workflow `Create Tag and Release`.
2. Set input `tag` (for example `v0.3.0`).
3. Optional: set `draft`, `prerelease`, and `upload_tos`.

## What gets published

### Linux installers

Generated by GoReleaser (`nfpms`) and uploaded to the GitHub release:

1. `.deb` packages
2. `.rpm` packages
3. `.tar.gz` archives

### Windows installer

Generated by Inno Setup from `scripts/setup.iss` and uploaded to the GitHub release:

1. `PicoClawSetup.exe`

### macOS installers

Generated in two matrix jobs (`amd64`, `arm64`) and uploaded to the GitHub release:

1. `picoclaw-launcher-macos-amd64.dmg`
2. `picoclaw-launcher-macos-arm64.dmg`

## Workflow details

Main workflow: `.github/workflows/release.yml`

Installer jobs added:

1. `windows-installer`
2. `macos-installer`

Both jobs run after the GoReleaser release job and upload artifacts to the same release tag using `gh release upload --clobber`.

## Notes

1. Linux is already covered by GoReleaser package outputs.
2. Windows and macOS installers are built in dedicated OS-native jobs.
3. macOS job currently applies ad-hoc signing before DMG creation.
